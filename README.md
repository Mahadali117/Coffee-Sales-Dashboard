# Coffee-Sales-Dashboard

## Project Overview

This project is an interactive Microsoft Excel dashboard that analyzes coffee sales data from January 2019 through August 2022. It allows users to explore sales performance by coffee type, roast type, customer, country, and month.

The project demonstrates my ability to clean and organize data, use Excel formulas, create PivotTables, build interactive charts, and communicate business insights through dashboard design.


## Key Insights

- Total sales reached approximately **$45.1K**.
- The **United States** generated approximately **79% of total sales**.
- **Excelsa** was the highest-selling coffee type, generating approximately **$12.3K**.
- **Light roast** represented the largest share of sales at approximately **39%**.
- **Allis Wilmore** was the highest-value customer.
- Monthly sales fluctuated significantly throughout the reporting period.

## Dashboard Features

- Interactive Coffee Type slicer
- Total sales KPI
- Top-performing country KPI
- Top-selling coffee type KPI
- Monthly sales trend analysis
- Top five customers by sales
- Sales comparison by coffee type
- Sales distribution by roast type

## Project Workflow

1. Reviewed and organized the original sales data.
2. Cleaned missing, duplicate, and inconsistent values.
3. Used Excel formulas to combine and retrieve related information.
4. Created PivotTables to summarize sales performance.
5. Developed charts for customers, coffee types, roast types, and monthly trends.
6. Connected a slicer to the dashboard for interactive filtering.
7. Designed and formatted the final dashboard for clear presentation.
